## Goodbye AIO-Switch-Updater-Reborn — Hello SwitchBlade

Thank you for using AIO-Switch-Updater-Reborn. The project is officially retiring and continues under a new name and codebase: SwitchBlade.

- Stronger foundation with an updated Borealis UI
- Unified mods, cheats, CFW updates, and tools in one place
- Reliability and maintainability improvements across the board

What happens now:
- This app no longer starts its traditional UI. It only downloads and installs SwitchBlade automatically.
- You can also install manually: copy the SwitchBlade/ directory to /switch/ on your SD card.

Quick links:
- SwitchBlade repository: https://github.com/exploitz86/SwitchBlade
- SwitchBlade releases: https://github.com/exploitz86/SwitchBlade/releases

Issues, feature requests, and translations now live in the SwitchBlade repo. Your support and feedback are still very welcome — thanks for being part of the journey!
